# FindDiskKiller 1.2.6

This release makes whole-system activity visible inside Active Apps, so the
table accounts for work that macOS cannot reliably assign to a user-facing app.

## New

- Add a stable `macOS & Storage Layer` row to Active Apps with CPU, total write,
  current write, peak write, average download, and average upload statistics.
- Aggregate system services, filesystem work, short-lived processes, and other
  activity that cannot be safely attributed to one visible application.
- Keep the system row visible in the Top 12 table and include it in column
  sorting, with Current Write descending as the default order.

## Accuracy and interaction

- Calculate the system row from comparable per-window host totals minus visible
  process attribution instead of presenting an unexplained global remainder.
- Preserve real gaps when a source is unavailable, a counter is invalid, or a
  process identity cannot be compared; unknown values are never replaced by
  zero.
- Treat a newly observed process as a new attribution baseline, leaving its
  first-window activity in the system layer instead of invalidating every
  metric in the row.
- Start network averages from the latest continuous valid segment after source
  warm-up or recovery, while still showing a gap for a current interruption.
- Freeze the system row together with application rows during hover and paused
  live following, preventing the table from moving under the pointer.
- Add a dedicated explanation popover for the aggregate row without changing
  application details or file-tracing behavior.

## Release integrity

- Build 119 passed 282 local tests, lint checks, an isolated Debug build, and
  real-window validation across all six system-layer columns before release.
- The release build is universal, signed, notarized, Gatekeeper-validated, and
  Sparkle-signed before publication.
- Existing AI Storage safeguards remain unchanged: analysis never starts
  automatically, scanner database access remains read-only, and cleanup uses
  only supported provider capabilities.
