# FindDiskKiller 1.3.11

This release gives every primary workspace a quieter, more consistent header
that follows the visual structure established by Now.

## Unified page headers

- Remove the framed header containers from Applications, Disks, History, and
  Settings so titles and controls sit naturally within each workspace.
- Align page titles, leading spacing, and vertical rhythm with the Now view for
  more predictable navigation throughout the app.
- Remove boxed header icon treatments and the redundant divider beneath the
  History header.
- Simplify the About header by removing its surrounding glass border while
  preserving the existing brand presentation.

## Responsive layout

- Keep titles and page controls on one line when space allows.
- Reflow controls beneath the title in narrow windows so actions remain
  readable, reachable, and free from clipping.
- Preserve stable header dimensions and shared spacing through a tested layout
  contract.

## Release integrity

- Build 133 passed the serial Swift test suite, lint checks, Xcode archive, and
  release validation workflow.
- The release is universal, Developer ID signed, notarized,
  Gatekeeper-validated, and Sparkle-signed before publication.
