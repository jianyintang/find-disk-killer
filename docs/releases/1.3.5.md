# FindDiskKiller 1.3.5

This hotfix restores file and volume activity tracing after an app update when
macOS is still running an older privileged tracing helper.

## Fixes

- Replace a protocol-incompatible tracing helper transactionally: unregister the
  old service, wait for its XPC endpoint to disappear, register the helper from
  the current signed app, and verify the new protocol handshake before reporting
  success.
- Retry legacy helper cleanup and discard failed XPC connections so temporary
  launch-service or connection races recover without restarting the Mac.
- Let a trace attempt perform the authoritative helper handshake when launch-time
  reconciliation is stale, while preserving strict local trace/update exclusion.
- Report an existing trace and an active update installation as distinct states;
  tracing no longer labels every interlock failure as an update in progress.

## Release integrity

- Build 127 passed the complete serial test suite, including helper replacement,
  legacy cleanup, reconnection, trace/update interlock, and localization tests.
- The release build is universal, signed, notarized, Gatekeeper-validated, and
  Sparkle-signed before publication.
