# FindDiskKiller 1.2.4

This release supersedes 1.2.3 with an artifact produced from a verified clean
release checkout. It contains the same monitoring and layout improvements, with
no behavioral changes beyond 1.2.3.

## Improvements

- Show physical-device writes, writes attributed to visible processes, the
  unattributed remainder, and process coverage in the same sampling window.
- Keep continuously active applications individually identified in bounded
  daily history and explain the legacy Other aggregate accurately.

## Fixes

- Use stable history identities for applications launched from changing
  temporary paths and merge compatible legacy identities without changing
  stored totals.
- Prevent the Apps list from shifting after search and keep long localized
  controls aligned in narrow windows.
- Require signed Sparkle release notes during update checks.

## Release integrity

- Build 117 was produced from a clean, committed checkout and passed the full
  local test, signing, notarization, Gatekeeper, and Sparkle verification gates.
- Existing AI Storage safeguards remain unchanged: analysis never starts
  automatically, scanner database access remains read-only, and cleanup uses
  only supported provider capabilities.
