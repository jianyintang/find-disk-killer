# FindDiskKiller 1.3.18

This release improves Storage Map accounting, analysis feedback, and layout
stability, and reduces rendering work on the Now dashboard while preserving
live sampling and animated transitions.

## Storage Map accuracy and controls

- Measure allocated storage using individual file identities, including sparse
  files and hard links, and reconcile overlapping roots across sources and
  volumes without counting the same file twice.
- Keep source refreshes consistent with the shared accounting session, reject
  stale progress, and avoid mixing an earlier scan's totals with current work.
- Resolve symbolic-link roots consistently and surface incomplete provider
  inventories instead of presenting them as complete results.
- Clarify whether cleanup moves data to Trash or uses a provider's official
  command, and avoid submitting nested cache targets twice.
- Keep completed results available after stopping analysis; returning to
  Storage Map no longer restarts a stopped first scan automatically.

## Analysis feedback and layout

- Show subtle shimmer on existing analysis text and controls and rolling
  numeric transitions for real progress, without inserting a new status block
  or shifting the page.
- Fix overlapping responsive layouts and align table headers with their rows
  around width breakpoints. Preserve readable capacity units in narrow windows.
- Respect reduced-motion preferences and keep all new interface text localized.

## Now performance

- Render disk trend paths and the CPU core grid with native Core Animation
  layers, preserving animated updates, hover inspection, and accessible data.
- Isolate dashboard updates and remove duplicate chart and numeric layouts to
  reduce repeated SwiftUI work while retaining the selected sampling interval.
- Stop unnecessary animation when windows are occluded or reduced effects are
  enabled, and refresh layer appearance when the display or theme changes.
- Reduce repeated root resolution and growing-array copies during storage
  analysis. Performance reports in the repository describe measurements and
  their limits; results vary with workload and hardware.

## Compatibility

- macOS 14 or later; universal Apple silicon and Intel application.
- Version 1.3.18, build 140.
