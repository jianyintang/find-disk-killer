# FindDiskKiller 1.3.3

This release redesigns the Now experience around faster scanning, clearer disk
activity, and dependable access to per-application details.

## Improvements

- Rework the Now dashboard with a more balanced physical-device throughput
  layout that adapts cleanly to one internal disk or multiple external disks.
- Redesign the single-application overview and file-activity views while
  preserving search, sorting, filtering, pause and resume, Finder reveal, path
  copy, and deep-trace workflows.
- Keep the live file-activity table responsive during I/O bursts by retaining
  the latest 240 events while cumulative throughput and operation totals remain
  accurate.
- Add focused read and write filters to the recent file-activity table.

## Fixes

- Make application-row activation independent of hover tooltips and popovers,
  using stable row hit testing so a click consistently opens the requested
  application details.
- Give each application detail window a stable identity and bring it forward
  after creation, preventing the main window or an active popover from hiding
  it.
- Keep Storage Map discovery alive when the user briefly visits the page and
  navigates away, so returning never leaves discovery stuck indefinitely.
- Transition directly from source discovery into automatic analysis without
  flashing the first-run screen or shifting the page layout.

## Release integrity

- Build 125 passed all 443 non-privileged tests, including a 20,000-event
  retention stress test, plus the official Codex and Claude cleanup fixtures.
- The release build is universal, signed, notarized, Gatekeeper-validated, and
  Sparkle-signed before publication.
