# FindDiskKiller 1.3.2

This patch release restores official Codex cleanup for tasks stored outside the
default Codex data directory and completes the English interface localization.

## Fixes

- Launch the official Codex app server with the selected scan source as
  `CODEX_HOME`, so capability checks and permanent deletion operate on the
  same task store.
- Support symlinked and non-default Codex homes, including `.codex-cc`, while
  retaining canonical-path verification before any deletion is enabled.
- Preserve compatibility with supported Codex alpha, beta, and
  release-candidate builds by validating the real `thread/delete` protocol
  instead of rejecting prerelease version labels.

## Localization

- Complete English translations for interface copy that previously fell back
  to Chinese in cleanup, settings, and storage workflows.

## Release integrity

- Build 124 passed all 438 non-privileged tests and the official Codex and
  Claude cleanup fixtures.
- The release build is universal, signed, notarized, Gatekeeper-validated,
  and Sparkle-signed before publication.
