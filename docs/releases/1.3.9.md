# FindDiskKiller 1.3.9

This release adds a complete menu bar-only workflow so FindDiskKiller can stay
available without occupying the Dock, while preserving the visual performance
controls and full-speed analysis behavior introduced in 1.3.8.

## Menu bar workflow

- Add a menu bar-only option in Settings that hides the Dock icon without
  preventing the main window from being opened when it is needed.
- Open the main window by clicking the non-control area of the menu bar panel.
- Keep collection and stop controls directly in the panel, with a clear idle
  state when monitoring is not active.
- Add an explicit Quit App action that terminates the app normally without
  opening the main window or relaunching the process.

## Interaction and compatibility

- Keep buttons and other controls inside the menu bar panel from accidentally
  triggering the main-window action.
- Restore the appropriate macOS activation policy when switching between Dock
  and menu bar-only modes.
- Localize the new settings, states, actions, tooltips, and accessibility copy
  across all ten shipped languages.
- Preserve Low, Balanced, and Full visual effect levels, including smooth
  leftward curve motion and glass materials in the modes where they are enabled.
- Keep dedicated and batch analysis at full CPU concurrency for fast results.

## Release integrity

- Build 131 passed the serial Swift test suite and release validation workflow.
- The release is universal, Developer ID signed, notarized,
  Gatekeeper-validated, and Sparkle-signed before publication.
