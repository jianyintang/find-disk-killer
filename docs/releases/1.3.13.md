# FindDiskKiller 1.3.13

This release improves the Storage Map source list so its space information and
actions remain readable at smaller window sizes.

## Storage Map layout

- Keep measured storage values visible when the source list is constrained,
  moving secondary cleanup information into a stacked layout when necessary.
- Give the reanalysis action its own trailing column so it never covers a
  source's measured storage value.
- Allow source descriptions to yield space before primary storage numbers and
  actions, preserving scan results and click targets across narrow layouts.

## Release integrity

- Build 135 passed the serial Swift test suite, lint checks, Xcode archive, and
  release validation workflow.
- The release is universal, Developer ID signed, notarized,
  Gatekeeper-validated, and Sparkle-signed before publication.
