# FindDiskKiller 1.3.4

This release makes software updates easier to find, prevents a completed update
session from blocking file tracing, and completes localization for dynamic
container-storage details.

## Improvements

- Move the current version and manual update check into About, while keeping the
  automatic daily update preference in General settings.
- Present Docker and Podman storage titles, capacity breakdowns, object counts,
  and reference status in the selected app language.
- Add release-blocking localization coverage for app and Core-generated UI text,
  including structured localization keys and arguments for dynamic content.

## Fixes

- Reconcile Sparkle's real session state while checking or installing an update,
  so a missed completion callback cannot leave tracing permanently blocked by
  “An update is being checked or installed.”
- Keep previously cached storage snapshots compatible after adding localization
  metadata to resource nodes.

## Release integrity

- Build 126 passed the serial CI suite and targeted update, navigation,
  localization, and storage-cache compatibility tests.
- The release build is universal, signed, notarized, Gatekeeper-validated, and
  Sparkle-signed before publication.
