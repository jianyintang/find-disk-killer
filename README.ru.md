<p align="center"><sub>Найдите длительную дисковую активность и приложения, которые её вызывают.</sub></p>

Когда Mac нагревается, а диск остаётся занятым, одного списка процессов часто
недостаточно, чтобы понять причину. FindDiskKiller строит расследование вокруг
приложений: обнаруживает длительную нагрузку, находит главное приложение и
показывает его ЦП, дисковый ввод-вывод, сеть, файлы и накопители в одном контексте.

## Учитывает и пространство AI Agents

AI Storage измеряет данные Codex и Claude только после явного запуска и относит распознанный объём к конкретным thread/session, основным чатам и рекурсивным субагентам. Измеренные файлы и оценки базы данных показаны отдельно; неполные свидетельства не выдаются за точные.

<p align="center"><img src="docs/assets/screenshots/ai-storage-overview.webp" width="100%" alt="Обзор AI Storage с раздельным пространством чатов, общими и неатрибутированными данными Codex и Claude."></p>

<p align="center"><img src="docs/assets/screenshots/ai-storage-threads.webp" width="100%" alt="Codex AI Storage с активностью и субагентами по thread, а также полным составом хранилища выбранного thread справа."></p>

Выберите возраст, проект или отдельные чаты и проверьте ожидаемое немедленное освобождение до безвозвратного удаления. Codex использует официальный thread/delete, автономные сессии Claude Code — официальный Agent SDK. Активные, изменённые или неподдерживаемые элементы пропускаются без прямой записи в SQLite и ручного удаления transcript. Claude Desktop/Cowork сейчас удаляются в Claude Desktop.

## Главное на одном экране

| Раздел | Что он показывает |
| --- | --- |
| **Активность приложений** | ЦП, чтение, запись, загрузка и отправка за последние 5 секунд; сортировка, изменение ширины столбцов и нативные значки |
| **Временная шкала** | Ломаные графики за 1 минуту, 15 минут и 1 час с точным временем и значениями при наведении |
| **Сведения о процессе** | Отдельные окна для сравнения ЦП, диска, сети и файловых данных приложения |
| **Файловая активность** | Открытые сейчас расположения и каталоги, изменения в которых наблюдались за последние 5 минут |
| **Трассировка доступа** | По запросу: объёмы запрошенного чтения/записи, скорость за 5 секунд, пики сеанса, активные файлы и проверенные процессы |
| **Диски** | Пропускная способность физических устройств под понятными именами подключённых томов, включая внешние накопители |
| **Состояние накопителя** | Температура, запись хостом, износ, резерв, история питания и ошибки, если macOS предоставляет эти данные |
| **Строка меню** | Ненавязчивый обзор текущей активности без повторяющихся уведомлений |

## Единый контекст расследования

```text
Длительная активность
        |
        v
Главное приложение  -->  ЦП / диск / загрузка / отправка
        |
        v
Открытые файлы и недавние изменения
        |
        v
Необязательная ограниченная трассировка файла или папки
        |
        v
Физическая пропускная способность и доступные данные о состоянии
```

ЦП всегда показан первым. Чтение и запись, загрузка и отправка разделены.
Текущие значения рассчитываются за последние пять секунд. При изучении строки
приостанавливается только её визуальная пересортировка, но щелчок продолжает
работать. Сведения о процессах открываются в отдельных окнах.

## Без ложной точности

- **Дисковый ввод-вывод приложения** берётся из счётчиков процесса и охватывает все используемые им накопители.
- **Пропускная способность устройства** берётся из физических счётчиков и отображается под понятными именами вроде `Macintosh HD` или `ExternalSSD`.
- **Недавние изменения** означают, что macOS заметила изменение; сами по себе они не определяют ответственный процесс.
- **Трассировка доступа** измеряет байты, запрошенные успешными системными вызовами. Кэш, отложенная запись APFS, сжатие, копирование при записи, отображение памяти и пробелы наблюдения отличают их от физической или NAND-записи.
- **Состояние накопителя** содержит только поля, которые действительно сообщает macOS. Отсутствующие значения остаются недоступными и не превращаются в ноль.

FindDiskKiller не утверждает, что способен точно сопоставить каждый байт процесса определённому физическому диску.

## Конфиденциальность и разрешения

Мониторинг и анализ выполняются локально. В текущей версии нет рекламы,
телеметрии, поведенческой аналитики и сторонних SDK отслеживания. Приложение не
отправляет активность процессов, пути, историю мониторинга или серийные номера дисков.

Для базового мониторинга права администратора не нужны. Только при явном запуске
трассировки файла или папки macOS может запросить разрешение для подписанного
фонового компонента. Он может контролировать лишь ограниченный по времени сеанс
`/usr/bin/fs_usage` с фиксированными параметрами и не способен запускать shell
или произвольные команды.

Подробнее: [Политика конфиденциальности](PRIVACY.md) и [Политика безопасности](SECURITY.md).

## Требования и установка

- macOS 14 или новее
- Mac с Apple silicon или Intel
- Учётная запись администратора нужна только для включения трассировки доступа по запросу

После выпуска официальные версии распространяются в виде universal2 DMG с подписью Developer ID и нотариальным заверением Apple.

1. Скачайте последнюю версию с [официального сайта](https://finddiskkiller.com/ru/download/).
2. Откройте DMG и перетащите FindDiskKiller в «Программы».
3. Запустите FindDiskKiller из папки «Программы».

Для каждой версии публикуется SHA-256. Не обходите Gatekeeper, если пакет не проходит проверку.

## Сборка и тестирование

Для разработки требуются Xcode 16 или новее и XcodeGen 2.42.0 или новее.

```bash
git clone https://github.com/jianyintang/find-disk-killer.git
cd find-disk-killer
xcodegen generate
xcodebuild -project FindDiskKiller.xcodeproj \
  -scheme FindDiskKillerApp -configuration Release \
  -destination 'generic/platform=macOS' \
  CODE_SIGNING_ALLOWED=NO ONLY_ACTIVE_ARCH=NO build
swift test
```

Неподписанная сборка для разработки позволяет проверить базовый мониторинг, но
не привилегированную трассировку файлов или папок. Приложение и helper взаимно
проверяют Team ID сопровождающего, поэтому этот сценарий нужно тестировать на
официально подписанной сборке. Одобрение фонового компонента и полный доступ к
диску для защищённых расположений являются отдельными разрешениями macOS.

Создание подписанной и нотариально заверенной версии из чистого коммита:

```bash
make lint test
make release VERSION=1.0.0 BUILD_NUMBER=100
```

Артефакты с `SKIP_NOTARIZATION=1` предназначены только для локальной проверки и не подлежат публикации.
